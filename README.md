# Toolkit for Molecular Biology and Protein Bioinformatics

## Description

This toolkit is written as a programming exercise to gain experience in building reusable, testable and reliable code. The bioinformatics toolkit can also be used in later protein design and small molecule drug design projects. After implementing my own basic functions I will bring in existing libraries such as Biopython and Biotite to more closely resemble tools used in a real drug development pipeline. 

## Getting Started


### Installation

- Clone the repository
- Create virtual environment: `conda env create --name molbio_prot_env --file environment.yml`
- `conda activate molbio_prot_env`

## Help

Update `environment.yml` file with:
```
conda env export --name molbio_prot_env --from-history --file environment.yml
```
